# 双人同行 · 工具棚（Twin Steps）

仿《双人成行》风格的 Three.js 3D 合作平台跳跃游戏原型（单人版：两个角色轮流操控）。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 ，点击「开始冒险」（会锁定鼠标，按 Esc 暂停）。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 鼠标 | 移动 / 视角 |
| 空格 | 跳跃，空中再按二段跳 |
| Shift | 冲刺（空中可用一次） |
| C | 空中重踏 |
| E | 互动（拉杆）；小梅在空中靠近钉子时用锤子勾住摆荡 |
| 左键 | 小梅挥锤 / 小柯掷钉 |
| 右键（或 Q） | 小柯瞄准 |
| R | 小柯召回所有钉子 |
| Tab | 切换角色 |
| V | 分屏 / 单屏 |
| M | 静音 |

## 关卡流程

1. 工作台：移动、跳跃、二段跳教学
2. 书堆跳台：二段跳 + 空中冲刺跨越长距离
3. 纸箱墙：压力板开门（一人踩板、一人通过，再从里面帮对方开门）
4. 尺子跷跷板：一人站蓝端，另一人重踏红端把同伴弹上高台；高台拉杆启动电梯接同伴
5. 旋转木桥：小柯把钉子钉进木齿轮让木桥停下
6. 摆荡深渊：小柯把钉子钉进空中木靶，小梅用锤子勾住钉子摆荡过去，再砸按钮放下吊桥
7. 灰尘怪竞技场：踩、重踏、锤击消灭敌人，钉子可以钉晕；砸箱子拿收集品
8. 移动平台 → 爱情魔法书（两人都到达即通关）

## 结构

- `src/core/` 输入、合成音效与音乐、Rapier 物理封装、粒子
- `src/entities/` 角色控制器与程序化动画、模型、钉子系统、各类机关与敌人
- `src/level/` 关卡布局、工具棚环境与光照
- `src/game/` 主循环（分屏渲染）、相机
- `src/ui/` HUD、字幕

所有模型、贴图、音效都是代码程序化生成的，没有外部素材。

开发模式下控制台可用 `sim(秒数, 按住的键, 单次按下的键)` 和 `tp(角色, x, y, z)` 调试，例如 `tp(game.may, 0, 11, -124)`。
